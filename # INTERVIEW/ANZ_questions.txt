Compress retrieved documents before sending them to the LLM.
Benefit: Saves tokens and focuses the model on the most relevant information.

How do we implement it?
LangChain already provides this.

model = CrossEncoder("cross-encoder/ms-marco-MiniLM-L-6-v2")
pairs = [
    (query, doc.page_content)
    for doc in docs
]
scores = model.predict(pairs)

ranked_docs = sorted(
    zip(docs, scores),
    key=lambda x: x[1],
    reverse=True
)
top_docs = [doc for doc, score in ranked_docs[:3]]


2. Sentence Transformers
Split into sentences.
Generate embeddings.
Compare each sentence with the query.
Keep only the most relevant sentences.

Example:
from sentence_transformers import SentenceTransformer, util
model = SentenceTransformer("all-MiniLM-L6-v2")

sentences = [
    "The scheme started in 1995.",
    "Required documents are Aadhaar and Income Certificate.",
    "The application can be submitted online."
]

query = "What documents are required?"
query_emb = model.encode(query)
sentence_emb = model.encode(sentences)
scores = util.cos_sim(query_emb, sentence_emb)
best_sentence = sentences[scores.argmax()]

## How to reduce hallucinations in a RAG pipeline

1. **Retrieve high-quality documents**

   * Use a good embedding model.
   * Retrieve only relevant documents.

2. **Use Hybrid Search**

   * Combine **BM25 + Vector Search** to improve retrieval accuracy.

3. **Apply a Reranker**

   * Re-rank the retrieved documents and send only the most relevant ones to the LLM.

4. **Optimize Chunk Size & Overlap**

   * Use appropriate chunk sizes (e.g., 300–600 tokens) with some overlap to preserve context.

5. **Retrieve the Right Number of Chunks (Top-K)**

   * Don't send too few or too many chunks. Typically, Top-3 to Top-5 works well.

6. **Write Strong System Prompts**

   * Example: *"Answer only from the provided context. If the answer is not in the context, say 'I don't know.'"*

7. **Use Metadata Filtering**

   * Filter by document type, date, language, user role, or source before retrieval.

8. **Use High-Quality, Updated Knowledge Base**

   * Remove outdated, duplicate, and incorrect documents.

9. **Ground Every Answer in Retrieved Context**

   * Do not allow the model to answer from its own knowledge when the context is insufficient.

10. **Return "I don't know" When Context Is Missing**

    * It's better than generating incorrect information.

11. **Add Citations/Source References**

    * Show which document or page the answer came from, improving trust and verification.

12. **Use Query Rewriting**

    * Rewrite ambiguous user queries before retrieval to improve search accuracy.

13. **Validate the Response**

    * Use a second LLM or rule-based validator to verify that the answer is supported by the retrieved context.

14. **Continuously Evaluate Retrieval Quality**

    * Measure metrics like Context Precision, Recall, Faithfulness, and Answer Relevance, then tune the pipeline.

---

### Interview answer (30–45 seconds)

> "To reduce hallucinations in a RAG pipeline, I first ensure high-quality retrieval using hybrid search (BM25 + vector search). Then I apply a reranker to select the most relevant chunks, optimize chunk size and Top-K retrieval, and use metadata filtering. I instruct the LLM to answer only from the retrieved context and return 'I don't know' if the information isn't available. Finally, I include source citations and continuously evaluate retrieval quality using metrics like faithfulness and answer relevance."
